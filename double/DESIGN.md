# 双色球历史数据分析工具 — 详细设计文档

## 一、项目概述

### 1.1 目标
打造一个可复用的双色球历史开奖数据分析工具，让用户能够：
- 主动查询历年（2003年至今）双色球完整开奖记录
- 通过可视化图表直观理解号码分布规律
- 获得基于统计的智能选号参考建议

### 1.2 适用场景
- 双色球爱好者研究历史规律
- 数据分析学习者练手项目
- 彩票店/资讯站点的数据看板

## 三、数据来源

### 3.1 数据源
| 来源 | 覆盖范围 | 获取方式 |
|------|----------|----------|
| datachart.500.com | 2003年(03001期) ~ 2024年(24001期) | HTTP GET + GB2312 解析 |
| cwl.gov.cn API | 2024年 ~ 至今 | REST API JSON |

### 3.2 数据字段
每条开奖记录包含：
```
{
  "Issue": "26085",        // 期号
  "Date": "2026-07-26",    // 开奖日期
  "Red": "06,09,13,17,24,28",  // 6个红球
  "Blue": "15",            // 蓝球
  "RedSum": 97             // 红球和值（计算得出）
}
```

### 3.3 数据更新机制
- 每次打开页面时，自动拉取最新数据
- 本地缓存 `ssq_data.json`，避免重复请求
- 可手动触发全量数据刷新

## 四、分析模块详解

### 4.1 红球频率分析
- **统计维度**：33个号码各自在3482期中的出现总次数
- **冷热判定**：与理论均值（约633次）比较，偏离±20为热/冷号
- **图表呈现**：柱状图 + 每个柱子顶部标有具体次数 + 颜色区分
  - 🔴 红色柱 = 热号（>660次）
  - 🔵 蓝色柱 = 冷号（<610次）
  - ⚫ 灰色柱 = 正常区间

### 4.2 蓝球频率分析
- **统计维度**：16个蓝球各自出现次数
- **图表呈现**：与红球相同风格，确保辨识度

### 4.3 和值走势
- **定义**：每期6个红球号码之和（范围21~183，实际29~172）
- **近100期折线图**：展示和值的波动情况
- **黄色虚线**：标注全历史均值102
- **全历史和值分布图**：展示3482期和值在各区间的分布密度

### 4.4 连号分析
- **定义**：同一期中两个相邻号码同时出现（如07和08）
- **统计**：历史最常见的相邻号码组合，按次数排名
- **可视化**：带进度条的卡片展示

### 4.5 三区分布
- **一区(1-11)**、**二区(12-22)**、**三区(23-33)**
- 统计各区间号码出现频次
- 帮助判断号码分布的冷热区域

## 五、智能推荐引擎

### 5.1 推荐逻辑
基于以下维度综合输出参考建议：

1. **热号优先**：推荐历史高频出现的号码
2. **冷号回补**：标记长期偏低的号码（统计学回归均值倾向）
3. **奇偶均衡**：建议奇偶比保持约5:5或4:6
4. **和值参考**：推荐和值在80~130区间（历史占比约70%）
5. **连号提示**：展示常见连号组合

### 5.2 输出格式
```
🔴 红球建议关注：
   · 热号：14、01、22、26、17（历史高频）
   · 冷号：33、28、21、29、31（可能回补）
   · 奇偶比约 51:49，建议保持均衡
   · 和值集中在 80-130 区间

🔵 蓝球建议关注：
   · 热门：01、16、15
   · 冷门：08、10、13（可能反弹）

🔗 连号参考：07-08、32-33、16-17 最常见

⚠️ 彩票完全随机，以上仅为统计参考
```

## 六、技术实现

### 6.1 技术栈
- **数据获取**：PowerShell `Invoke-WebRequest`
- **数据处理**：PowerShell 脚本解析
- **可视化**：纯 HTML5 Canvas（零外部依赖）
- **数据存储**：JSON 格式

### 6.2 项目文件结构
```
double/
├── ssq_data.json          # 3482条历史开奖数据
├── ssq_analyzer.html      # 主分析看板（交互式可视化）
├── fetch_data.ps1         # 数据获取脚本
├── DESIGN.md              # 本设计文档
└── README.md              # 使用说明
```

### 6.3 使用方式
1. 双击打开 `ssq_analyzer.html` 即可查看完整分析
2. 如需刷新数据，运行 `fetch_data.ps1`
3. 6个标签页自由切换查看不同维度
