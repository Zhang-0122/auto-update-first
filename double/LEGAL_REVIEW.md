# 合法合规审查与修改建议

## 核心原则

本项目只能做彩票开奖信息整理、历史数据统计和中奖核验，不能暗示预测未来开奖结果，不能诱导购彩。

## 页面必须明确展示

1. 数据来源：中国福彩网/中彩网、中国体彩网等官方公开渠道。
2. 数据更新时间：页面生成时间和最新开奖期号。
3. 免责声明：本页面只做历史数据整理和统计参考，不预测开奖结果。
4. 理性购彩提示：彩票有风险，未成年人不得购买彩票。
5. 核验提示：最终中奖结果以官方公告和彩票机构兑奖规则为准。

## 当前不合理或需要弱化的地方

| 位置 | 问题 | 建议 |
| --- | --- | --- |
| 选号参考 | 容易被理解成推荐中奖号码 | 改成“统计参考”，说明不是预测 |
| 热号/冷号 | 用户可能误解为趋势判断 | 增加“历史频率不代表未来概率”提示 |
| 页面标题 | 如果强调“智能”会有误导 | 使用“开奖查询与统计参考” |
| 数据同步 | 如果未显示来源和时间，可信度不足 | 顶部加入来源和更新时间 |
| 多彩种扩展 | 各彩种规则不同 | 建立规则引擎，不能套用双色球规则 |

## 推荐免责声明文案

本页面基于中国福彩网/中彩网、中国体彩网等公开开奖信息整理，仅用于开奖记录查询、历史统计和中奖核验参考。彩票开奖结果具有随机性，历史统计不代表未来开奖结果，也不构成购彩建议。中奖结果、奖级和兑奖规则以官方公告及销售机构规定为准。请理性参与，未成年人不得购买彩票。
