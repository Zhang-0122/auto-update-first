# 双色球开奖查询与统计参考

这个工具的目标很简单：让别人拿到文件夹后，能查询历年开奖记录，看懂号码分布，并获得基于统计的选号参考。

## 快速使用

### 普通用户推荐方式

直接双击：

```text
ssq_analyzer.html
```

这个网页已经内嵌历史开奖数据，不需要启动服务器，也不需要别人敲命令。

### 维护者刷新数据

```powershell
python run_app.py
```

刷新最新数据后再打开：

```powershell
python run_app.py --update
```

第一次换到新电脑使用时，如果提示缺少依赖，请先运行：

```powershell
pip install -r requirements.txt
```

## 用户能做什么

| 功能 | 说明 |
| --- | --- |
| 历史查询 | 按年份或期号查看 2003 年至今的开奖记录 |
| 中奖核验 | 选择期号后输入 6 红 + 1 蓝，自动判断命中和奖级 |
| 批量核验 | 一次粘贴多行号码，逐行判断中奖结果 |
| 数据总览 | 第一屏展示最新开奖、总期数、和值均值和核心统计 |
| 红球分析 | 红球使用暖色系，柱条越长代表出现次数越多 |
| 蓝球分析 | 蓝球使用冷色系，方便和红球视觉区分 |
| 和值走势 | 查看近 100 期红球和值波动和历史均值线 |
| 选号参考 | 输出高频、低频、连号和选号区间参考 |

## 文件说明

## 为什么之前点开空白

旧版页面尝试用浏览器读取本地 `ssq_data.json`。很多浏览器会拦截本地文件读取，所以页面能打开但图表为空。

现在 `build_dashboard.py` 会把数据直接写进 `ssq_analyzer.html`，网页不再依赖本地 `fetch`，别人双击也能看。

## 同类项目参考

我参考了 `xtwguw/Docker-ssq-dlt-cxc` 的使用思路：它更像一个面向普通人的彩票工具入口，而不是只给开发者看的图表。我们当前版本吸收了这几个方向：

| 参考点 | 当前实现 |
| --- | --- |
| 用户先查记录 | 首页默认就是历史查询 |
| 最新开奖醒目 | 顶部展示最新一期红蓝球 |
| 数据和功能分区 | 历史查询、频率、和值、推荐分开 |
| 降低部署门槛 | 不需要 Docker，直接 Python 或双击 HTML |

下一步创新方向已经整理到 `INNOVATION_PLAN.md`，重点是中奖核验、开奖后自动更新、图片识别和可解释推荐。

当前版本已完成中奖核验和批量核验。下一步可以继续做开奖后自动更新或图片识别。

## 数据刷新和失败保护

维护者运行 `python run_app.py --update` 会联网刷新数据并重新生成 `ssq_analyzer.html`。若网络异常或数据源暂时不可用，程序会保留原来的 `ssq_data.json`，不会把已有数据覆盖坏。

刷新日志和备份文件会放在：

```text
D:\SKILL DOUBLE rewards\cashe
```
