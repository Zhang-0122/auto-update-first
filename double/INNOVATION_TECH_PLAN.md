# 面向大众使用的创新点方案

## 产品创新

1. 一页式开奖工具：最新开奖、历史查询、核验、统计在同一页面完成。
2. 大众模式 / 分析模式：默认简单，展开后看专业统计。
3. 官方来源可见：每个彩种显示数据来源、最新同步时间和校验状态。
4. 不预测式选号参考：只解释历史统计，不制造中奖暗示。
5. 多彩种统一体验：福彩、体彩不同玩法共用同一套页面逻辑。

## 技术创新

1. 静态网页自动更新：GitHub Actions 定时生成 `index.html`，大众访问时不需要服务器。
2. 官方数据校验层：抓取后先检查期号、日期、号码范围、重复项，再决定是否发布。
3. 彩种配置化：用配置描述号码结构和开奖规则，减少硬编码。
4. 规则引擎：中奖核验独立于页面展示，后续新增彩种不破坏已有功能。
5. 单文件发布：最终产物仍是一个 `index.html`，适合 Netlify 免费托管。
6. 失败保护：更新失败时不覆盖旧数据，避免线上页面变坏。

## 页面创新

1. 开奖公告式顶部：最新期号、开奖号码、数据来源、更新时间直观呈现。
2. 彩种切换不迷路：福彩/体彩分组，用户先选彩种再查数据。
3. 核验优先：大众用户最关心“我中没中”，核验入口要靠前。
4. 统计卡片解释原因：比如高频、低频、和值区间、奇偶结构，每项一句解释。
5. 权威免责声明常驻底部，不打扰但可见。

## 不做的创新

1. 不做“预测中奖”。
2. 不做“AI杀号”。
3. 不做诱导购彩文案。
4. 不默认要求用户注册登录。
